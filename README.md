## 项目初衷

本项目仅为一套业务创意与计量规则框架，**非成品商业软件**。灵感来源：马斯克的议价机器人垂直agent Hagglebot，本人预判可能需要独立第三方审计agent作为商业配套。

当前垂直领域执行Agent（议价Agent、采购Agent等）普遍会向企业客户承诺降本收益，由厂商自行上报节约金额，天然存在美化口径的可能性。

本框架提出一套独立第三方审计机制，作为「边线裁判」：不参与业务谈判，只核验收益真实性，计算上报值与独立核算值之间的**偏离度**，可作为企业与Agent服务商商务结算的参考依据。

开源初衷：抛砖引玉，验证思维前瞻性（20261017提出），验证这套创意是否具备落地价值。

## 核心概念

1. 执行Agent（前锋）：例如Hagglebot议价机器人，负责谈判，输出节约成本的业绩报告。
2. 审计裁判（本框架）：独立第三方，数据源隔离，不隶属于执行Agent厂商，不参与交易博弈。
3. 越位：收益统计口径失真、归因错误、越权承诺，导致上报的节约金额不成立。
4. 偏离度：【厂商上报节约金额 - 第三方独立核算金额】/ 基准价，量化两份报告之间差异。

## 框架能力范围

- 定义基准价选取规则
- 剥离市场行情波动对价格的影响
- 计算净节约金额，识别隐藏成本（账期、售后、质保风险）
- 生成对照审计报告，计算两份报告的偏离度
- 提供参考合同条款：可将第三方审计结果作为效益分成结算依据
- 本框架本身为一套【垂直审计Agent】设计方案，包含知识库、技能、提示词体系的整体构想


## 重要限制（必读）

1. 本框架**不含行业成交知识库**。知识库是商业化落地的核心资产，需要使用者自行采集、清洗、维护。
2. 本框架仅输出参考评估结论，**不构成法律仲裁结果**。商务争议、法务维权，仍需要专业法务人员介入。
3. 本框架不能消除所有模糊归因问题。市场剧烈波动、独家垄断供应链场景，天然存在计量争议。
4. 本项目只是理论框架+演示demo，无法直接部署上线给大企业商用。商用需要额外工程、数据、客户成功团队。
